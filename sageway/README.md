# 세이지웨이(SAGEWAY) 기업 홈페이지

온라인몰 정산자동화 · 온라인 쇼핑몰(국내/해외) 구축 · 판촉물·기념품 기획 및 제작, 세 사업을 소개하는 원페이지 정적 사이트입니다.
빌드 도구나 프레임워크 없이 파일 세 개로 동작합니다.

```
sageway/
├─ index.html   섹션 마크업(인라인 SVG 포함)
├─ style.css    색 토큰 → 리셋 → 타이포 → 레이아웃 → 컴포넌트 → 섹션 → 반응형 → 다크 → 모션
└─ main.js      테마 전환, 헤더 현재 섹션, 목차 dialog, 국내/해외 탭, 브릿지 애니메이션, 문의 폼 검증·접수증, 복사 버튼
```

## 로컬에서 열기

파일을 더블클릭해도 열리지만, 폰트와 스크립트를 정상 환경에서 확인하려면 간단한 정적 서버를 권장합니다.

```bash
python -m http.server 8765 --directory sageway
```

브라우저에서 `http://localhost:8765/` 을 엽니다.

## 오픈 전에 바꿔야 하는 값

대괄호 `[ ]` 로 표시된 값은 모두 플레이스홀더이며, 붉은 점선 밑줄(`.ph` 클래스)로 표시됩니다. 실제 값으로 바꾼 뒤 `<span class="ph">` 래퍼를 지우면 밑줄이 사라집니다. `index.html` 에서 `ph` 로 검색하면 전부 찾을 수 있습니다.

| 위치 | 항목 |
| --- | --- |
| 회사소개 → 회사 명세서 | 대표자명, 설립연도, 주소, 사업자등록번호 (상단 '기재 예정' 도장 `.stamp--sq` 도 함께 삭제) |
| 판촉물 → 제작 사양서 | 문서번호 `SW-GD-[0000]`, 단가 |
| 문의 → 연락처 | 전화, 이메일 (선택 가능한 텍스트이며 '복사' 버튼이 붙어 있습니다) |
| 문의 → 개인정보 동의 | `[개인정보처리방침 링크 대체]` 를 실제 링크로 |
| 푸터 → 회사 정보 | 대표, 사업자등록번호, 통신판매업신고, 주소, 전화, 이메일, 개인정보처리방침·이용약관 링크 |
| `<head>` | `<title>`, `<meta name="description">` |

## 예시 데이터 표기

정산 대사표, 채널별 정산 주기, 주문-정산 검증표, 제작 사양서, 공정 소요 기간, 사례 3건은 모두 **예시**이며 실제 채널 정책이나 고객 데이터를 주장하지 않습니다.
실제 레퍼런스로 교체할 때는 `data-sample="true"` 속성이 붙은 블록(사례, 미니 대사표)과 `.stamp--sample`, `.sample-caption` 을 함께 정리하세요. FAQ 의 회신 기한(영업일 1일), 쇼핑몰 구축 기간(4~8주), 최소 수량(100개)은 HTML 주석으로 '소유주 확정 값' 이라고 표시해 두었습니다.

## 문의 폼 연결

현재 폼은 백엔드 없이 동작하는 데모입니다. 검증을 통과하면 화면 안에 '접수증'을 그리고 실제 전송은 하지 않습니다.
실제 전송을 붙이려면 `main.js` 의 `form.addEventListener('submit', …)` 안, `renderReceipt(...)` 를 호출하기 직전에 `fetch()` 로 서버(또는 Formspree, Google Apps Script 같은 폼 서비스)에 보내고 성공 응답 후 접수증을 표시하도록 바꾸면 됩니다. 접수증의 "이 페이지는 데모이며 실제 전송은 도입 시 연결됩니다." 문구도 그때 삭제하세요.

## 디자인 시스템 메모

- 색은 전부 `style.css` 상단의 `:root` 토큰입니다. 다크 모드는 `prefers-color-scheme` 을 따르고, 헤더·목차·푸터의 '밝게 / 어둡게' 스위치로 강제할 수 있습니다(`localStorage` 의 `sw-theme`).
- 서체는 Google Fonts 세 가족만 씁니다: Gothic A1(800/900), IBM Plex Sans KR(400/500/600), IBM Plex Mono(400/500/600). 금액·번호·날짜는 항상 `.mono` 또는 `.num` 클래스(고정폭, tabular-nums).
- 인주 붉은색(`--seal`)은 도장, 불일치 행, 폼 오류, 여백선에만 씁니다. 큰 면을 붉게 채우지 마세요.
- 그림자·둥근 모서리·그라디언트 배경은 쓰지 않습니다. 깊이는 괘선 굵기(1px / 2px / 이중선)로만 만듭니다.
- 모든 시각물은 HTML/CSS/인라인 SVG 입니다. 외부 이미지가 없으므로 이미지 최적화 단계가 필요 없습니다.
