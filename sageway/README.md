# 세이지웨이(SAGEWAY) 기업 홈페이지

온라인 쇼핑몰 국내/해외 구축 및 운영, 판촉물·기념품 기획 및 제작 — 두 사업을 소개하는 원페이지 정적 사이트입니다.
빌드 도구나 프레임워크 없이 파일 세 개로 동작하며, JavaScript가 꺼져 있어도 모든 내용이 그대로 보입니다.

```
sageway/
├─ index.html   섹션 마크업(헤더 → 히어로 → 쇼핑몰 → 판촉물 → 일하는 방식 → 자주 묻는 질문 → 문의 → 푸터)
├─ style.css    색 토큰 → 리셋 → 타이포 → 레이아웃 → 헤더 → 히어로 → 컴포넌트 → 푸터 → 반응형 → 다크 → 모션
└─ main.js      테마 전환, 모바일 메뉴, 이메일 복사 버튼 (편의 기능만; 없어도 사이트는 완성 상태)
```

## 로컬에서 열기

저장소 루트에서 정적 서버를 띄우고 브라우저에서 `http://localhost:8765/` 을 엽니다.

```bash
python -m http.server 8765 --directory sageway
```

파일을 수정하면 새로고침만으로 반영됩니다.

## 이메일 주소·회사 정보 바꾸기

- **이메일**: `index.html` 에서 `sageway9@gmail.com` 을 검색해 모두 바꿉니다. 히어로와 문의 섹션의 '메일로 문의하기' 버튼(`mailto:` 링크, 제목 자동 입력), 문의 섹션의 주소 표시(복사 버튼 대상), 자주 묻는 질문 답변, 푸터 링크에 있습니다.
- **회사 정보**(상호, 대표, 사업자등록번호, 주소): `index.html` 맨 아래 `<footer>` 안의 `site-footer__info` 목록에 있습니다.
- **`<title>` / `<meta name="description">` / OG 태그**: `<head>` 에 있습니다. 사업 영역 문구를 바꾸면 함께 맞춥니다.
- 판촉물 제작 공정의 소요 기간은 예시이며 각 항목에 '예시'로 표시되어 있습니다. 확정 값이 생기면 '예시' 표기를 함께 정리하세요.

문의 폼과 전화번호는 두지 않습니다. 문의는 이메일 한 곳으로만 받습니다.

## 디자인 메모

- 색은 전부 `style.css` 상단의 `:root` 토큰입니다. 다크 모드는 `prefers-color-scheme` 을 따르고, 헤더의 '어둡게 / 밝게' 버튼으로 바꿀 수 있습니다(`localStorage` 의 `sw-theme` 에 저장, 렌더 전에 적용).
- 서체는 Google Fonts 두 가족만 씁니다: Nanum Myeongjo(700, 제목), IBM Plex Sans KR(400/500/600, 본문).
- 장식은 1px 괘선과 세이지 한 색으로만 만들고, 인주 붉은색(`--seal`)은 히어로 첫 줄의 작은 점 하나에만 씁니다. 그림자·그라디언트·외부 이미지는 없습니다.
- 컨트롤 테두리(버튼, 복사, 메뉴, FAQ 표식)는 `--line-ui` 토큰을 씁니다. 지면과 세이지 면 위에서 명도 대비 3:1 이상이 되도록 잡은 값이므로 바꿀 때 대비를 다시 확인하세요.

## 배포

`main` 브랜치에 `sageway/` 아래 파일을 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 `index.html`, `style.css`, `main.js` 세 파일을 GitHub Pages 에 배포합니다. 서버 설정이나 빌드 단계는 없습니다.
